Kotoba Snap（以下称「本应用」）是一款日语单词学习工具：你拍摄或选择一张图片，本应用识别其中的日文，帮你把生词做成词卡并安排复习。

本政策说明本应用如何处理你的信息。**本应用没有账号系统，你无需注册或登录即可使用全部功能。**

## 1. 开发者不会接收的内容

我们（本应用的开发者）**没有任何服务器**，因此**不会接收或保存**以下任何内容：

- 你拍摄或选择的图片
- 图片中识别出的文字
- 你创建的词卡、备注与复习记录
- 你的姓名、邮箱、电话、位置或任何账号信息

本应用自身的代码不会把这些内容发送到任何地方。

这不等于「什么都不会离开你的设备」。有两条路径会：**你手机系统自己的备份功能**（第 2 节）和**本应用集成的 Google ML Kit 会发送的诊断信息**（第 4 节）。请一并阅读。

## 2. 你的数据保存在哪里

以下内容全部保存在**你设备上本应用的私有存储区**内：

- **源图片副本**：你拍摄或选择的图片会被复制一份到本应用的私有目录，用于日后回看词卡的出处。这个副本**不在系统相册中**，其他应用无法访问。
- **词卡数据**：表记、读音、词性、释义、你自己写的备注、JLPT 等级、与来源图片的关联。
- **复习记录**：每次复习的时间与你给出的评分。
- **应用设置**与使用计数。
- **词典索引**：由随应用附带的词典数据在本地生成的查找索引，不含你的任何输入。

你可以随时在「设置」中限制源图片的占用容量，或一次性清除全部源图片。删除词卡会同时删除其复习记录。

### 系统备份与换新手机

**本应用不提供由我们运营的云同步**，也不会把你的图片、词卡或复习数据发送到我们的服务器。

但**你手机操作系统自己的备份功能可能会备份并恢复本应用的部分数据**，具体取决于你的系统设置。当前版本的实际情况是：

| | iPhone（iCloud 备份） | Android（Google 自动备份） |
|---|---|---|
| 词卡、复习记录、设置 | 默认纳入系统备份 | 默认纳入系统备份 |
| 源图片副本 | **已明确排除**，不纳入备份 | **已明确排除**，不纳入备份 |

「默认纳入」指的是平台的默认行为，实际是否产生备份、能否恢复，取决于你是否开启了系统备份以及备份是否成功完成。

**两端都明确排除了源图片副本**，为的是减少你的照片在云端或迁移过程中的副本。在 Android 上，这一排除同时适用于云备份、换机时的设备间直传，以及向非 Android 设备的迁移。

因此换新手机后：**词卡与复习记录会回来，源图片不会**。「按来源图片」的分组仍然存在并可继续使用，只是显示占位图。

这些备份存放在**你自己的 Apple 或 Google 账户**里，我们无法访问。是否开启备份、如何删除已有备份，由你的系统设置与 Apple / Google 的政策决定。

**卸载本应用会删除本设备上的全部本地数据。** 如果你的系统此前已经备份过，那份备份的去留由上述平台的备份设置决定，不在我们的控制范围内。

## 3. 文字识别在你的设备上完成

本应用的文字识别（OCR）在**你的设备本地**运行：

- Android 使用 Google ML Kit 的设备端文字识别；
- iOS 主要使用 Apple 的 VisionKit，Google ML Kit 作为备用。

**你的图片与识别结果不会被发送给我们，也不会被发送给 Google。** 关于后者，Google 在 [ML Kit 服务条款](https://developers.google.com/ml-kit/terms) 中明确声明：使用 ML Kit API 时，输入数据（图片、视频、文本）的处理完全在设备上进行，ML Kit 不会把这些数据及其输出结果发送到 Google 的服务器。Apple 的 VisionKit 是系统自带的设备端能力，同样在本机完成识别。

日文分词、词典查询与复习安排同样完全在本地进行——词典数据随应用附带，不需要联网。

## 4. 第三方 SDK 会收集的诊断信息

**本应用会联网，我们不能声称任何数据都不离开你的设备。**

本应用集成的 Google ML Kit SDK 会自动向 Google 发送有限的诊断与使用指标。**当前版本未提供关闭该 SDK 遥测的应用内设置。**

根据 Google 的官方数据披露（[Android](https://developers.google.com/ml-kit/android-data-disclosure) / [iOS](https://developers.google.com/ml-kit/ios-data-disclosure)），这些信息包括：

**两个平台共同的字段**

- 设备信息（厂商、型号、操作系统版本与 build）
- 应用包名 / Bundle ID 与版本
- 按安装的标识符——Google 声明其**并非**用于唯一识别用户或物理设备
- 性能指标（如处理延迟）
- API 配置（如图片格式与分辨率）
- 事件类型与错误码

**仅 Android 侧另有**

- 输入 / 输出尺寸、功能版本

Google 声明这些数据经 HTTPS 加密传输，且不与第三方共享。**这些诊断指标中不包含你的图片或识别出的文字**——如第 3 节所述，Google 在 ML Kit 服务条款中对此有明确声明。

关于 Google 如何处理这些数据，请参见 [Google ML Kit 条款与隐私](https://developers.google.com/ml-kit/terms) 与 [Google 隐私权政策](https://policies.google.com/privacy)。

除上文所述的 ML Kit 诊断与使用指标外，本应用**不包含**广告 SDK、通用行为分析 SDK 或崩溃上报 SDK。

## 5. 权限

| 权限 | 用途 |
|---|---|
| 相机 | 仅在你选择「拍照」时使用，用于拍摄要识别的图片 |
| 照片 / 相册 | 仅在你选择「从相册导入」时使用。本应用只获得你当次选中的那张图片，不会读取你的相册全部内容 |

本应用不请求定位、通讯录、麦克风、电话或短信权限。

在 Android 上，本应用自身不声明任何权限。应用信息页可能显示 `INTERNET` 与 `ACCESS_NETWORK_STATE`，它们来自第 4 节所述的 Google ML Kit 组件。

## 6. 儿童

本应用不面向 13 岁以下儿童设计。本应用没有账号系统，**不要求姓名、邮箱、生日等任何身份信息**。

图片与词卡的存放位置、以及系统备份如何处理它们，见第 2 节；Google ML Kit 的诊断信息见第 4 节。这些处理方式对所有用户一致，包括儿童使用的情况。

## 7. 你的权利

**我们不在自有服务器上持有你的任何内容**，因此你对这些内容的控制完全在你的设备上进行：

- **查看**：所有词卡与源图片都可在应用内查看。
- **删除**：可删除单张词卡、清除全部源图片，或卸载应用删除本设备上的全部数据。
- **导出**：当前版本暂不提供导出功能。

两个我们无法代你操作的例外：

- **系统备份**中的那份副本，请在你的 iCloud / Google 账户备份设置里管理（第 2 节）。
- **Google ML Kit 收到的诊断数据**由 Google 持有，请参见第 4 节的 Google 隐私政策链接。我们既不掌握也无法代为删除，因此不会向你承诺一个我们做不到的删除通道。
